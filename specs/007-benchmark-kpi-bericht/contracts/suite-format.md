# Contract: Suite Format

A suite is a directory `bench/suites/<name>/`. Nothing in it is ever used for training (FR-005).

## `suite.toml`

```toml
name = "chemie"
version = 1

[files]                       # path (relative to the suite) -> SHA-256; all are checked first
"facts.tsv" = "…"
"sets/unseen.tsv" = "…"
"sets/unknown.tsv" = "…"
"sets/offtopic.tsv" = "…"
"sets/s3.tsv" = "…"
"text/s1.txt" = "…"
"text/s2.tsv" = "…"
"../../../training/data/eval/kurzarbeit.tsv" = "cd2a36bfba2b0a267831dba497ad1f0197675a9d3ff39d6c86e87711bcf60aaa"

[sets]                        # role -> file
unseen = "sets/unseen.tsv"
unknown = "sets/unknown.tsv"
offtopic = "sets/offtopic.tsv"
kurzarbeit = "../../../training/data/eval/kurzarbeit.tsv"
s3 = "sets/s3.tsv"
s1 = "text/s1.txt"
s2 = "text/s2.tsv"

refusal_forms = ["Das weiß ich leider nicht.", "Frag mich etwas zur Chemie!",
                 ": dazu habe ich keine Angabe."]
explain_max = 60

[value_classes.symbol]
kind = "vocab"
case_sensitive = true

[value_classes.number]
kind = "number"
decimals = 2
units = ["u", "g/mol"]

[properties.element_symbol]
value_class = "symbol"
canonical = "Welches Symbol hat {name}?"

[thresholds]                  # FR-018, clarified 2026-11-23; "exact" = any change counts
F1 = 3.0                      # percentage points
F2 = 0.5
F3 = 3.0
F4 = 3.0
F5 = 3.0
F6 = "1%"
T1 = "5%"
T2 = "5%"
T3 = "5%"
R1 = "exact"
R2 = "exact"
R3 = "exact"
R4 = "exact"
S1 = 0.02                     # bits per character
S2 = "1 step"
S3 = 2                        # answers

[board_sample]
unseen = 30                   # first N items of the unseen set
kurzarbeit = "all"
typed = 15                    # first N of the sample also asked typed (100 ms per character)
t3 = ["un/181", "un/182"]     # ids of long prompts for T3 (10 in total)

[s2]
distances = [16, 32, 64, 96, 128, 192, 256, 416]
recall_ratio = 0.5
recall_min = 0.8

not_applicable = []           # KPI ids that do not apply to this topic
```

Paths outside the suite directory are allowed only for files pinned in `[files]`.

## `facts.tsv`

```text
object	object_name	property	value
Na	Natrium	element_symbol	Na
Na	Natrium	element_ordnungszahl	11
Na	Natrium	symbol_element	Natrium
H2O	Wasser	verbindung_molare_masse	18,02
```

`value_class` comes from the property. The known values of a `vocab` class are all `value`s of
properties in that class plus all `object_name`s when the class is a name class.

## Question sets (`sets/*.tsv`, `kurzarbeit.tsv`)

```text
id	grade	kind	question	expected
un/001	8	fact	Welches Kürzel hat Kalium im Periodensystem?	element_symbol: K
un/150	9	multi	Ordnungszahl und Masse von Neon?	element_ordnungszahl: Ne | element_atommasse: Ne
uk/001	9	unknown	Welche Formel hat Brolmiumchlorid?
ot/001	-	refuse	Wie spät ist es in Tokio?
s3/001	-	explain	Hallo, wer bist du?
```

`grade` is informative (`-` allowed). Every `property` in `expected` must exist in `suite.toml`, and
every object in `facts.tsv` (load error otherwise).

Minimum sizes (FR-003): chemie unseen ≥ 200 covering every property, unknown ≥ 40, offtopic ≥ 40,
s3 = 20; allgemein unseen ≥ 60.

## `text/s1.txt`

UTF-8 text with two marked halves; lines starting with `#` are comments, not scored:

```text
# topic
…≥ 10,000 characters…
# general
…≥ 10,000 characters…
```

## `text/s2.tsv`

```text
id	distance	target_start	target_len	text	control
```

Generated by `tools/bench_s2.py`; `text` and `control` have the same length.
